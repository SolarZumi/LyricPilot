# LyricPilot

<img src="extension/icons/128.png" width="64" height="64" alt="LyricPilot 图标">

Chrome 歌词对齐扩展。导入带时间的歌词，选择网页播放按钮，再通过点击或按住按钮、空格及自定义按键，自动完成网页上的歌词标记。

需要已有歌词时间轴，不会从音频识别歌词或生成时间轴。

## 安装

**只需 Chrome 123 或更新版本，无需 Node.js、Python，也无需安装依赖或执行命令。**

1. 下载本仓库并解压。
2. 打开 `chrome://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择 `extension` 文件夹。
4. 打开歌词编辑网页，点击工具栏中的 LyricPilot 图标。

更新时替换文件，在扩展管理页点击刷新，再刷新歌词编辑网页。

## 使用

1. 在网页中载入歌曲和歌词，复位到第一句，将歌曲暂停在开头。
2. 导入歌词文件，确认歌曲版本、分句与时间轴一致。
3. 选择网页上的播放按钮。
4. 选择标记方式：网页按钮、空格键或自定义按键。网页按钮模式还需选择标记按钮。
5. 选择“单击”或“按住”，点击“开始对齐”。
6. 完成后检查网页上的记录，再手动保存。

“按住”需要每句都有明确的结束时间。缺少持续时间或时间范围重叠时不可用。

面板可拖动和收起。更多设置支持按 0.1 秒调整时间偏移、切换深浅色与配色。“退出”关闭面板。

对齐期间暂时拦截网页鼠标操作，面板仍可使用。点击“暂停”或按 Esc 可恢复操作。按住一句时暂停会提前结束该句，继续时从下一句开始；需要完整句尾时请复位后重新对齐。

## 歌词格式

支持 LRC、TSV、SRT、VTT，以及采用这些时间格式的 TXT。不支持 JSON 或没有时间标记的纯文本。示例文件见 [examples](examples/)。

TSV 使用 UTF-8 编码，列之间用 Tab 分隔，时间单位为秒：

```tsv
start	end	text
0.8	2.2	第一句歌词
3.5	5.0	第二句歌词
```

普通 LRC 只有开始时间，适合单击。每个文件最多 3 MB、3000 句。

## 兼容性与隐私

- 扩展点击选定的网页播放按钮，并跟随网页音频的实际进度。
- 支持 HTML audio/video，以及 DistroKid 歌词同步页面使用的 WaveSurfer 播放器。其他纯 Web Audio 播放器、跨域 iframe 和封闭 Shadow DOM 可能无法使用。
- 网站可能拒绝脚本生成的输入。“对齐完成”表示操作已发出，请检查网站是否正确记录。
- 已完成本地验证，包括 DistroKid 同版本的 WaveSurfer 播放进度与按住录入测试；各平台的实际提交结果仍需在网页中确认。
- 仅使用 `activeTab`、`scripting`、`storage` 权限；点击扩展后访问当前网页。
- 歌词和音频不上传。没有麦克风权限、分析追踪或远程脚本；外观和位置设置保存在本机。
- DistroKid 播放进度适配仅在其歌词同步页面启用，读取播放器时间与状态，不读取账号或付款信息。
